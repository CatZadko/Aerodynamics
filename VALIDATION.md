# Проверки исходников

Целевая среда: Paper 26.3 build 241, Java 25.

До остановки сборочных работ проверено:

- Предыдущая ревизия компилировалась с Paper API `26.3.build.241-stable`, `-Xlint:deprecation -Werror`.
- 13 JUnit-тестов предыдущей ревизии прошли: прогрессия, вероятности, ограничитель нагрузки и расчёт физики.
- Плагин предыдущей ревизии загружался на настоящем Paper 26.3 build 241; bootstrap регистрировал зачарование, сервер завершал запуск.
- Серверная проверка подтвердила создание и сериализацию книг/упряжек I–V, планирование слияния и применения книг,
  запрет IV+IV, проверку ингредиентов кузнечного стола и отклонение несогласованного PDC.

Полный интеграционный прогон не завершён: проверочная программа ошибочно ожидала, что
`RecipeChoice.empty().test(ItemStack.empty())` возвращает true. Этот предикат API всегда возвращает false;
отсутствие ингредиента задаётся специальным объектом `RecipeChoice.empty()`. Ошибка была в тестовом утверждении.

В финальных исходниках дополнительно уточнена обработка имени при применении книги к обычной упряжке
и использован `RecipeChoice.itemType` вместо устаревающего `MaterialChoice`.
Финальная ревизия повторно не собиралась. В архиве нет скомпилированного плагина.

Не проверены с подключённым игровым клиентом: клики по результатам наковальни/кузнечного стола,
зачарование на столе, фактический полёт пассажиров, задержка отправки чанков и взаимодействие с другими плагинами.
Расчёт установившейся горизонтальной скорости сверялся с байткодом официального сервера;
это не заменяет измерения полёта на конкретном сервере.

Сценарии ручной проверки находятся в README.md. Тестовые серверы, их миры, логи и проверочный служебный плагин
в поставку исходников не включены.
